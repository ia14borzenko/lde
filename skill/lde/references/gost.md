# Оформление по ГОСТ 7.32-2017 (делает LDE; агенту — знать, не верстать)

Оформление задаёт преамбула `lde/tex/preamble.tex` (со ссылками на пункты стандарта).
«П» = проверяется программно в `lde docx` / `lde submit`; «Ч» = требуется человек.

## Страница и текст
- П A4, одна сторона. Поля: левое 30 мм, правое 15 мм, верхнее/нижнее 20 мм (п.6.1.1).
- П Times New Roman, кегль не менее 12 пт (шаблон: 14 пт), чёрный (п.6.1.1).
- П Межстрочный интервал 1,5; абзацный отступ 1,25 см, одинаковый по тексту (п.6.1.1).
- П Выравнивание по ширине; полужирный только в заголовках (п.6.1.1).
- П Нумерация страниц арабскими, внизу по центру, сквозная, без точки (п.6.3.1).
- П Титульный лист входит в нумерацию, но номер не ставится (п.6.3.2).

## Структура и заголовки
- П Обязательные элементы: титул, содержание, введение, разделы, заключение,
  список использованных источников, приложения (п.4, 5.1–5.11).
- П Названия структурных элементов — по центру, ПРОПИСНЫМИ, без точки, каждый
  с новой страницы (п.6.2.1). Каждый раздел — с новой страницы.
- П Заголовки разделов/подразделов: с абзацного отступа, после номера, с
  прописной буквы, полужирным, без точки (п.6.2.3). Переносы запрещены (п.6.2.4) — Ч.
- П Нумерация разделов 1, подразделов 1.1, пунктов 1.1.1, без точки в конце (п.6.4).

## Рисунки
- П Подпись «Рисунок N — Наименование» по центру ПОД рисунком, без точки (п.6.5.7).
- П Сквозная нумерация (или в пределах раздела — допустимо, п.6.5.6); приложения — А.1 (п.6.5.5).
- Ч Рисунок расположен после первого упоминания/на следующей странице (п.6.5.1); ссылка в тексте обязательна.

## Таблицы
- П Подпись «Таблица N — Наименование» слева НАД таблицей, без абзацного отступа (п.6.6.3).
- П Линии слева/справа/сверху/снизу; шапка при переносе повторяется (п.6.6.3, 6.6.6).
- П Заголовки граф — с прописной, по центру; строк — по левому краю (п.6.6.5–6.6.6).

## Формулы
- П Отдельной строкой, по центру строки, номер справа в круглых скобках (п.6.8.3).
- П Нумерация сквозная (1) или в приложении (В.1); ссылка «в формуле (1)» (п.6.8.4).
- Ч Выше/ниже формулы не менее одной свободной строки; пояснение символов с новой строки, начиная со слова «где» (п.6.8.1–6.8.2).

## Ссылки и источники
- П Номера ссылок в квадратных скобках [1] (п.6.9.1), сплошная нумерация.
- П Список источников — в порядке появления, арабские цифры с точкой, с абзацного отступа (п.6.16).
- Ч Библиографические описания по ГОСТ 7.1/7.80/7.82 — проверяется человеком.

## Приложения
- П «ПРИЛОЖЕНИЕ А» — по центру вверху страницы, заголовок отдельной строкой
  полужирным по центру (п.6.17.3); обозначения А, Б, В... (без Ё, З, Й, О, Ч, Ъ, Ы, Ь).
- П Нумерация объектов в приложении: Рисунок А.1, Таблица А.1, (А.1) (п.6.5.5, 6.6.4, 6.8.5).
- П Все приложения перечислены в СОДЕРЖАНИИ (п.6.17.7).

## Содержание
- П Отдельный абзац на запись, номер страницы справа, отточие (п.6.13).
- П Включены введение, разделы/подразделы, заключение, список источников, приложения (п.5.4.1).
