# Формат LDE-текста (text/*.md) — полностью

Файлы разделов читаются по имени (`01-…`, `02-…`) или в порядке `files` из `lde.toml`.
Блоки разделяются пустой строкой. Абзац — лучше одной строкой (diff по абзацам).

## Блоки

| Блок | Синтаксис |
|---|---|
| раздел / подраздел / пункт | `# Название {#sec:имя}` · `## …` · `### …` — номер ставит LDE |
| структурный элемент без номера | `# Введение {-}` · `# Заключение {-}` (печатается по профилю: прописными или как есть) |
| приложение | `# Название приложения {.appendix #app:имя}` → «ПРИЛОЖЕНИЕ А», нумерация объектов А.1 |
| абзац | любой текст; если сразу после формулы начинается с «где» — печатается без отступа |
| выносная формула | `$$ LaTeX $$ {#eq:имя}` — с номером; без `{#eq:…}` — без номера. Можно в несколько строк между `$$` |
| рисунок | `![Подпись](путь){#fig:имя width=0.8}` · путь — `figures/…` или `calc/<расчёт>/out/…` |
| рисунок с подрисунками | `::: figure {#fig:имя}` / `![а) …](a.png)` / `![б) …](b.png)` / `Общая подпись` / `:::` |
| таблица | `: Заголовок {#tab:имя}` + строки `| … |` (вторая — `|---|---|`) · из CSV: `: Заголовок {#tab:имя file=calc/x/out/t.csv}` |
| перечисление | `- пункт` (тире по ГОСТ) · `1) пункт` · `а) пункт`; вложенность — отступ 2 пробела |
| листинг | ```` ```python ```` … ```` ``` ```` |
| комментарий (не печатается) | `<!-- … -->` |
| разрыв страницы | `::: pagebreak` |

Атрибуты в `{…}`: `#метка`, `-` (без номера), `.appendix`, `width=0.8` (доля ширины), `place=float`
(разрешить перенос рисунка; по умолчанию стоит на месте), `cols=2` (подрисунков в ряд).

## Ручное оформление блока

Строка `{style …}` прямо над блоком (без пустой строки) задаёт его оформление вручную — LDE
перестаёт подгонять этот блок автоматически; действует в PDF и DOCX. В Studio — флажок «Ручное
оформление» в панели элемента. Линтер перечисляет такие блоки (`lde check --all`, «к сведению»).

```
{style align=center indent=0 before=6 after=-2 line=1 size=12 bold=no italic=yes keep=yes newpage=yes}
Абзац, оформленный вручную.
```

| Параметр | Значение | Для |
|---|---|---|
| `align` | `justify` · `left` · `center` · `right` | абзац, заголовок, рисунок |
| `indent` / `left` / `right` | отступ первой строки / слева / справа, см | абзац, заголовок (`indent` — и перечисление) |
| `before` / `after` | добавка к обычному интервалу, pt (можно отрицательную) | все |
| `line` | межстрочный, множитель как в Word (1; 1,15; 1,5; 2) | абзац, заголовок, перечисление |
| `size` | кегль, pt | все (у рисунка — подпись, у таблицы — текст таблицы) |
| `bold` / `italic` | `yes` / `no` | абзац, заголовок, перечисление |
| `newpage` / `keep` | с новой страницы / не отрывать от следующего | `newpage` — кроме формулы; `keep` — абзац, заголовок, перечисление |

Выделение отдельных слов — в тексте: `**полужирный**`, `*курсив*` (в Studio — Ctrl+B / Ctrl+I).

## Вставки в тексте (в абзацах, подписях, ячейках, пунктах)

| Вставка | Пример | Результат |
|---|---|---|
| величина | `{R_ц}` | *R*ц (курсив, прямой кириллический индекс) |
| число расчёта | `{=csa.R0}` | «1150 м» (единица и точность — из calc.toml) |
| число в других единицах | `{=csa.f0 ГГц}` · `{=csa.Tp мкс}` | «3 ГГц» · «5 мкс» (только приставки СИ) |
| точность | `{=csa.alpha .3}` (3 знака после запятой) · `{=x .3g}` (значащие) | |
| без единицы | `{=csa.N -}` | |
| ссылка | `@fig:x` `@tab:x` `@sec:x` `@app:x` → номер; `@eq:x` → «(N)» | слово («рисунке») пишешь сам |
| источник | `[@key]` · `[@key, с. 45]` · `[@a; @b]` | «[3]», «[3, с. 45]», «[3, 4]» / «[15–18]» |
| формула в строке | `$\alpha = \lambda / d$` | |
| жирный / курсив | `**…**` / `*…*` — по минимуму | |
| экранирование | `\{` `\}` `\$` `\@` `\*` | |

Внутри формул (`$…$` и `$$…$$`) — те же вставки в виде команд: `\q{R_ц}` (величина) и
`\val{csa.PRF}` / `\val{csa.R0 км}` (число расчёта), например
`$$ f_{\text{ср}} = \frac{1}{2\pi \q{R} \q{C}} = \val{afc.f_c} $$ {#eq:fc}` — число в формуле
обновится вместе с расчётом. В Studio их вставляют кнопками «+ Величина / + Число» редактора формулы.

Размеры — как в MathType: индексы 58 %, индексы индексов 42 %; числитель и знаменатель `\frac`
всегда полного размера (и в тексте, и в скобках), в индексе — размера индекса; явная малая дробь — `\tfrac`. Не оборачивай содержимое
скобок в `\begin{matrix}…\end{matrix}` (так делал RDE) — пиши `\left\{ … \right\}`.

Ключи величин — как пишется обозначение: `R_ц`, `f_0`, `φ_1`, `L_max21`, `ΔL_БЛ`, `β′`.
Пути чисел: `lde list values <расчёт>` показывает все готовые вставки.

## Файлы проекта

| Файл | Что |
|---|---|
| `lde.toml` | `[document]` профиль, нумерация (`continuous`/`section`), какие перечни печатать, `hyphenation = false` — текст без переносов слов (PDF и DOCX; в Studio: ⚙ → «Переносы слов»); `[title]` — титул |
| `quantities.toml` | `["R_ц"]` `meaning`, `unit`, необязательно `latex` (явный набор) |
| `abbreviations.toml` | `"РСА" = "радиолокатор с синтезированной апертурой"` (ключи — в кавычках) |
| `refs.bib` | BibTeX; поле `formatted` — готовое описание; `file` — файлы в `sources/<ключ>/` |
| `calc/<ключ>/` | `calc.toml` + скрипт (см. calc.md) |
| `documents/<ключ>/` | другой документ проекта: `document.toml` (`[document] name`, `[title]`; прочее наследуется от `lde.toml`) + `*.md`; команды — `lde -D <ключ> …` |
