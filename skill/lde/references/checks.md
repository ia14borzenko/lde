# Правила `lde check` и как их чинить

`lde check` — файл:строка, человеческое сообщение и подсказка; `lde check --json` — для разбора.
`lde fix` применяет предложенные замены (только по этой команде; каждая — точечная, с проверкой).

| Правило | Что значит | Как чинить |
|---|---|---|
| qty-as-text (ошибка) | обозначение величины набрано текстом: `Rц`, `R_ц`, `fоп`, `φ1`, `V =` | `{R_ц}`; выражение — `{R_ц}{D}({f_оп})` |
| qty-as-math (ошибка) | величина набрана формулой: `$R_{ц}$`, `$V=150\ \text{м/с}$` | `{R_ц}`; `{V} = {=csa.V}` |
| qty-unknown (ошибка) | `{X}` не объявлена | `lde new quantity X --meaning … --unit …` или исправь ключ (подсказка покажет похожие) |
| symbol-in-where (замечание) | в пояснении «где f – линейная частота, Гц;» обозначение набрано текстом и не объявлено | `lde fix` объявит величину (смысл и единица — из строки) и вставит `{f}` |
| number-typed (замечание) | число совпадает с выходом расчёта | `{=calc.путь}`; если совпадение случайное — оставь |
| unit-duplicated (замечание) | `{=csa.R0} м` → «1150 м м» | убрать единицу после вставки; в таблице — `{=x -}` |
| value-unknown / value-norun (ошибка) | нет такого числа / расчёт не запускался | `lde list values calc` / `lde update` |
| ref-as-text (замечание) | «рисунке 4», «формуле (5)», «(5)» набраны цифрами | `@fig:…` / `@eq:…` (`lde list labels`) |
| ref-unknown (ошибка) | `@fig:x` — нет такой метки | `lde list labels` |
| cite-as-text (замечание) | «[3]» набрано вручную | `[@ключ]` (`lde list sources`) |
| cite-unknown (ошибка) | нет источника в refs.bib | `lde new source …` |
| raw-latex (ошибка) | LaTeX-команда в тексте (`\textbf`, `\ref`, `\label`) | убрать: оформление делает LDE; формулы — в `$…$` |
| stale (ошибка) | рисунки/числа устарели относительно параметров | `lde update` |
| calc-failed (ошибка) | расчёт упал | журнал из подсказки; поправь скрипт; прошлые выходы целы |
| file-missing (ошибка) | нет файла рисунка | путь / `lde update` |
| unreferenced (замечание) | на рисунок/таблицу нет ссылки в тексте (ГОСТ требует) | «… на рисунке @fig:x» |
| gost-* (замечание) | точка в конце заголовка/подписи, «где:» с двоеточием | убрать |
| syntax (ошибка) | не закрыта формула `$$`, листинг, неверный хвост `{…}` | по сообщению |
| syntax (ошибка) | неверный параметр в `{style …}` или строка оформления отделена от блока пустой строкой | по сообщению |
| `manual-style` (к сведению) | у блока ручное оформление `{style …}` — оформление по ГОСТ к нему не применяется | ничего, если поставил пользователь; убрать — удалить строку `{style …}` (только по просьбе) |

Сборка PDF (`lde build`) при ошибке LaTeX называет элемент и строку исходника, например
«text/05.md:111 (Формула (22)) неизвестная команда LaTeX \thinsp в формуле».
