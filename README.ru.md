# LDE — составление отчётов по ГОСТ 7.32

[English](README.md) · **Русский**

Отчёт — это проект: текст по разделам, величины, расчёты со скриптами и параметрами, рисунки,
источники. Агент пишет и считает, автор проверяет и правит в **LDE Studio** — окне с настоящим
PDF, где любой элемент открывается щелчком. Номера, ссылки, перечни и оформление LDE ведёт сам;
устаревшие после смены параметров рисунки и числа видны сразу и обновляются одной кнопкой.
Результат — PDF (XeLaTeX) и DOCX для Word, которые всегда соответствуют исходнику.

## За 5 минут

```sh
git clone https://github.com/ia14borzenko/lde.git && cd lde
bin/lde doctor --fix    # TinyTeX, pandoc, venv — в домашний каталог, без sudo (сеть нужна только здесь)
bin/lde app install     # один раз: команда `lde` и ярлык «LDE Studio» в меню приложений
lde                     # открыть LDE Studio
```

После установки LDE запускается как обычное приложение: из меню («LDE Studio», раздел «Офис») или
командой `lde` в терминале — окно открывается отдельно, терминал сразу свободен. Открывается
последний проект (или `lde open <каталог>`; в каталоге проекта — он). Studio одна: повторный запуск
открывает ещё одно окно той же Studio (и указанный проект в ней); закрыли все окна — Studio
завершилась. Журнал — `studio.log` в кэше LDE. Убрать: `lde app uninstall`.

Или из терминала:

```sh
lde import-docx мой-отчёт.docx ~/Documents/LDE/мой-отчёт             # перенести Word-отчёт
lde open ~/Documents/LDE/мой-отчёт                                   # открыть
lde submit -C ~/Documents/LDE/мой-отчёт                              # PDF + DOCX + проверки
```

## Studio

- Посередине — документ (PDF). Щелчок по абзацу, формуле, рисунку, таблице открывает редактор
  справа; по титулу — настройки, по списку источников — карточку источника.
- В абзаце вставки показаны «чипами»: величины, числа из расчётов, ссылки, цитаты, формулы.
  «+ Величина / + Число / + Формула / + Ссылка / + Цитата» (Ctrl+K) вставляют их без синтаксиса.
- Формулы — визуальный редактор (MathLive), LaTeX — под спойлером. Таблица — сетка.
- Слева: разделы, объекты, величины, расчёты (параметры правятся здесь), источники.
- Сверху: индикатор («Всё актуально» / «Устарело: N → Обновить» / «Замечаний: N»),
  «Что изменилось» (правки агента по элементам, откат каждой), «Вернуть», PDF, Word, «Сдать»,
  папка проекта, тема, настройки (⚙, Ctrl+,).
- Название проекта слева сверху — меню: документы проекта и «+ Новый документ», открыть проект,
  недавние, новый отчёт, импорт из Word, закрыть проект.
- Тема и масштаб запоминаются (`~/.config/lde/prefs.json`); проект открывается на том документе
  и той странице, где его закрыли (`.lde/studio-view.json`).
- «Ручное оформление» в панели элемента (по умолчанию выключено): выравнивание, отступы,
  интервалы, межстрочный, кегль, полужирный/курсив, «с новой страницы» для одного абзаца, заголовка,
  формулы, рисунка, таблицы — чтобы поправить неудачное место сразу, не дожидаясь исправления LDE.
  Хранится строкой `{style …}` над блоком, действует в PDF и Word; снять флажок — снова автоматически.
  Выделение слов: Ctrl+B / Ctrl+I.
- Каждая правка — git-коммит «Studio: …»; правки агента в это время подхватываются сами.

## Команды

| Команда | Что делает |
|---|---|
| `lde init <каталог>` | новый отчёт с примером (расчёт, формулы, таблица, источники) |
| `lde import-docx <файл.docx> <каталог>` | проект из Word-отчёта (формулы OMML и MathType → LaTeX, номера, ссылки, источники); отчёт — `import/report.md` |
| `lde import-rde <проект RDE> <каталог>` | разовая миграция проекта RDE (расчёты, величины, источники, вставки) |
| `lde` / `lde open [<каталог>]` | окно LDE Studio (фоном, одна Studio — повторно новое окно); `lde studio` — в этом терминале |
| `lde app install\|uninstall\|status` | команда `lde` в `~/.local/bin`, ярлык и значок в меню приложений |
| `lde check` / `lde fix` | линтер с файлом и строкой / применить предложенные им замены |
| `lde status` / `lde update` | что устарело и почему / пересчитать ровно устаревшее |
| `lde build` / `lde docx` / `lde submit` | PDF / DOCX с проверкой и ремонтом / всё вместе: «можно сдавать?» |
| `lde new quantity\|calc\|source\|abbr\|figure\|table\|formula\|section` | создать элемент или показать образец |
| `lde list quantities\|values\|labels\|sources\|calcs\|documents`, `lde info <метка\|расчёт>` | что есть в проекте, откуда рисунок/число |
| `lde new document <ключ> --title "…"`, `lde -D <ключ> <команда>` | ещё один документ проекта (ПЗ, ТЗ, статья) с общей базой; команды — для выбранного документа |
| `lde save -m "…"` / `lde undo` / `lde redo` | точка сохранения / отменить (повторно — предыдущее) / повторить |
| `lde version "…"`, `lde versions`, `lde history`, `lde diff <версия> [<версия>]`, `lde restore <версия>` | версии, история по сеансам, сравнение по элементам и пословно, откат (новой точкой) |
| `lde merge [--resolve uid ours\|theirs\|both]` | конфликты слияния (слияние по блокам подключено к git проекта) |
| `lde server login <адрес> <имя>`, `lde share new\|list\|pull\|accept\|reject\|reply` | сервер LDE; ссылка на документ для рецензента и приём его правок |
| `lde feedback check "…"`, `lde feedback new …`, `lde feedback analyze`, `lde feedback list` | обращения агентов: есть ли нужное в LDE; ошибка / нет инструмента / ручная рутина → `agent-feedback/` |
| `lde publish`, `lde sync`, `lde clone <id> <папка>`, `lde remote list\|member` | проект на сервере (зашифрован), синхронизация со слиянием по блокам, участники |
| `lde doctor [--fix]`, `lde skill-status` | инструменты; скилл агента `lde` (`~/.dsh/skills/lde` → `skill/lde`) |

## Сервер LDE

`lde-server/` — сервер в контейнере (развёртывание: `lde-server/deploy/deploy.sh <ssh-хост>`,
подробно — `lde-server/README.md`).
Ссылка на документ: получатель открывает ту же Studio в роли рецензента (страницы как у автора,
правка текста и формул, замечания) — в своей копии; автор разбирает правки в режиме сравнения
(две колонки страниц, F7, «Принять / Отклонить / Совместить», «Завершить» → версия): Studio →
меню проекта → «Ссылки и правки рецензентов» → «Разобрать правки».
Проекты хранятся зашифрованными, как на git-сервере. Сервер содержимого не видит.

## Проект отчёта

```
lde.toml            настройки: профиль (gost-7.32 | guap), нумерация, перечни, титул
text/*.md           текст по разделам (формат — skill/lde/references/format.md)
quantities.toml     величины: обозначение, смысл, единица
abbreviations.toml  сокращения
refs.bib            источники; файлы — sources/<ключ>/
calc/<ключ>/        расчёт: calc.toml (параметры) + скрипт; out/ — результаты (не в git)
figures/ data/      рисунки и данные
documents/<ключ>/   другие документы проекта: document.toml (имя, титул; остальное — из lde.toml) + *.md;
                    величины, сокращения, источники, расчёты, рисунки — общие
out/                PDF, DOCX, отчёты проверок (не в git)
```

## Для агента

**Подключить агента по ссылке (MCP).** Studio → меню проекта → «Подключить агента (MCP)…» →
«Включить» (или в терминале `lde mcp [<каталог>]`). Ссылка вида `http://127.0.0.1:8766/mcp?token=…`
постоянная (ключ — в `~/.config/lde/mcp.json`, 0600; «Новый ключ» отзывает старые). Окно даёт готовые
фрагменты: для DSH — файл `dsh --patch lde-mcp.yaml`, для Claude Code — `claude mcp add …`, JSON для
остальных; `lde mcp --stdio` — для клиентов, которые запускают сервер сами. Агенту без MCP-клиента
достаточно той же ссылки: GET по ней — описание среды, `POST …/mcp/tools/<инструмент>` — вызов.

Подключившись, агент сразу получает описание среды и порядок работы (instructions), а через
инструменты — всё, что нужно эксперту: `project_status/list/open/create` (в т. ч. импорт DOCX),
`lde_guide` (правила и формат), `outline`/`element`/`read`/`search`, `edit_element` (с защитой от
затирания правки автора)/`insert_element`/`write_file`, `new_quantity/abbr/source/calc`, `check`/`fix`,
`status`/`update`/`build`, `render_page` (страница PDF картинкой), `docx`/`submit`, версии
(`undo`/`redo`/`history`/`diff`/`restore`/`version_create`), слияние, правки рецензентов, обращения.
Агент работает в проекте, открытом в Studio; каждая его правка — точка «Агент …» в истории, Studio
пересобирает PDF и показывает, что сделано. Сервер слушает только 127.0.0.1, проверяет ключ, Host и Origin.

Скилл `skill/lde/SKILL.md` (установлен в DSH), правила — `docs/agent-rules.md`. Коротко:
величины — `{R_ц}`, числа — `{=расчёт.ключ}`, ссылки — `@fig:…`, источники — `[@ключ]`,
перед ответом — `lde check` до «Замечаний нет».

## Документация

`docs/guide/` — руководства (на английском) · `skill/lde/references/` — формат исходников, расчёты,
проверки, ГОСТ (для автора и агента) · `docs/agent-rules.md` — правила для агентов ·
`lde-server/README.md` — сервер · `docs/screens/` — экраны Studio.

toolchain/venv/bin/python -m unittest tests/unit/test_core.py   # логика, ломающаяся тихо

Требования: Linux, без sudo. TinyTeX, pandoc, venv — ставит `lde doctor --fix` (сеть нужна только
для установки; каталог инструментов — `~/.local/share/lde-tools`, другой — `LDE_TOOLS_DIR=…` в
`toolchain/local.env`). LibreOffice — для DOCX-проверок; Google Chrome — для окна Studio и UI-тестов.
