# Отчёт в LDE

Открыть в Studio: `lde studio` (из этого каталога). Собрать PDF: `lde build`. Проверить: `lde check`.

| Что | Где |
|---|---|
| текст по разделам | `text/*.md` |
| величины (обозначения) | `quantities.toml` |
| сокращения | `abbreviations.toml` |
| источники | `refs.bib`, файлы — `sources/` |
| расчёты (скрипты и параметры) | `calc/<имя>/` |
| рисунки и данные | `figures/`, `data/` |
| настройки документа и титул | `lde.toml` |
| готовые PDF и DOCX | `out/` |
