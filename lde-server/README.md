# Сервер LDE

Хранение проектов LDE и проверка документов по ссылке. Стандартная библиотека Python + SQLite,
без сторонних зависимостей; в контейнере. **Сервер не видит содержимого**: документы, правки
рецензентов, история проектов, названия шифруются на устройствах пользователей (AES-256-GCM,
X25519, PBKDF2 — `lde/crypto.py` и `web/static/crypto.js`, формат одинаковый).

## Установка (любой сервер с Docker)

Домен не нужен: `lde.<ip через дефисы>.sslip.io` указывает на ваш IP.

**За готовым nginx** — одной командой с рабочей
машины, повторный запуск — обновление:

    lde-server/deploy/deploy.sh <ssh-хост> [lde.<ip>.sslip.io]

Скрипт копирует `lde-server/` и MathLive в `/opt/lde-server-src`, собирает образ, запускает
контейнер на `127.0.0.1:8790`, при первом запуске создаёт сайт nginx и сертификат Let's Encrypt
(certbot --webroot); `nginx -t` — перед каждой перезагрузкой; остальные сайты не трогает.

**На чистой машине** (Caddy сам получит сертификат):

    cp lde-server/env.example lde-server/.env    # LDE_DOMAIN и LDE_PUBLIC_URL
    docker compose -f lde-server/compose.yaml --env-file lde-server/.env up -d --build

## Администрирование

    docker compose -f lde-server/compose.behind-proxy.yaml --env-file lde-server/.env exec lde-server lde-server <команда>

| Команда | Что |
|---|---|
| `invite --admin` / `invite --note "…"` | одноразовая ссылка-приглашение (7 дней); пароль задаётся в браузере |
| `users`, `disable <имя>`, `enable <имя>`, `delete-user <имя>` | пользователи |
| `backup /data/backup.tar.gz` | резервная копия (база + блобы + секрет); без ключей пользователей бесполезна |
| `gc` | удалить блобы, на которые ничто не ссылается |

Первый администратор: `invite --admin` → открыть ссылку → задать имя и пароль. Дальше приглашения —
в веб-панели (`/panel/`).

## Что умеет

- **Ссылка на документ** (`lde share new`, Studio → «Поделиться документом»): версия фиксируется,
  рецензент видит документ текстом, правит абзацы и оставляет замечания в своей копии; автор
  забирает правки в служебную ветку и принимает/отклоняет по блокам (слияние, конфликты).
  Токен ссылки — в пути (сервер хранит хеш), ключ — после `#` (на сервер не уходит). Срок, PIN, отзыв.
- **Проекты** (`lde publish | push | pull | sync | clone`, Studio → «Синхронизировать»): как git-сервер —
  зашифрованные пакеты `git bundle`, атомарное обновление веток («сравни и замени»), роли
  владелец / соавтор / рецензент / читатель; витрины версий (PDF) — в панели.
- **Панель** `/panel/`: вход, ссылки (метки расшифровываются в браузере), проекты, участники,
  приглашения, устройства.

## Безопасность

- Контейнер: не root, корневая ФС только для чтения (кроме тома `/data`), `cap_drop: ALL`,
  `no-new-privileges`, лимиты памяти/CPU/процессов; порт — только для прокси.
- Пароли: на сервер уходит ключ входа (PBKDF2 → HKDF), хранится `scrypt` от него; ключ шифрования
  остаётся на устройстве. Закрытые ключи пользователей — только зашифрованными.
- Cookie `HttpOnly; Secure; SameSite`, проверка CSRF, ограничение частоты (вход, PIN, ссылки),
  строгий CSP без встроенных скриптов и CDN, `Referrer-Policy: no-referrer`, HSTS, журнал действий
  без содержимого; журнал запросов nginx для сайта отключён (в путях — токены ссылок).
- Ограничение веб-шифрования: скрипты панели отдаёт сервер; при взломе сервера их можно подменить.
  Основной доверенный клиент — LDE.
